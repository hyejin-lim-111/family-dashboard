1. 이 폴더를 그대로 두거나, 아무 사이트(네이버 마이폴더, GitHub Pages, 개인 호스팅 등)에 올려요.

   - 위쪽 🔓 버튼으로 언제든 다시 고를 수 있어요. (기기 잠금)

⚙️ 설정에서: 프로필 사진 직접 업로드(기기 안 저장)·이름 수정, **채팅 알림 켜기/끄기**, 기록 파일 백업/복구, 도장판 새로 시작, 기기 동기화 상태 확인.

### 다인이 저녁 루틴 · 용돈 규칙

- 미션 탭의 **🌙 다인이 저녁 루틴**에서 오늘 한 항목을 체크하면 **+100원** 쌓여요.
- 그날 항목을 **모두 체크**하면 보너스 **+500원** (기본 4개면 하루 최대 900원).
- **모은 돈은 날짜가 바뀌어도 사라지지 않고 계속 누적돼요.** 그날 적립액은 `routine.days[날짜].earned` 로 기록에 굳어서, 다음 날이 되어도·체크를 풀어도·루틴 항목을 넣거나 지워도 줄지 않아요. 돈이 줄어드는 건 오직 **💰 용돈 쓰기** 뿐이에요.
- 미션 탭의 **🗓️ 용돈 달력**에서 하루하루 얼마를 모았는지(+900원), 보너스 받은 날(🎁), 용돈 쓴 날(-300원)과 **이번 달 적립 합계·지금 누적 잔액**을 한눈에 볼 수 있어요. 날짜를 누르면 그날 한 항목과 금액이 아래에 나와요.
- **💰 용돈 쓰기**로 다인이 쓴 금액을 빼고(쓴 날짜가 장부 `routine.spends` 에 남아 달력에 표시), **↺ 용돈 초기화**로 0원부터 다시 시작할 수 있어요(항목 목록은 유지).

### 글씨체

본문은 **Pretendard**(깨끗한 고딕) + Noto Sans KR 폴백으로, 태블릿과 부모님 폰에서 또렷하게 보이도록 대비·굵기·자간을 정돈했어요.

### 달력·체크리스트는 서로 어떻게 다른가요

- **달력(일정)** 은 날짜가 있는 한 번짜리 약속이에요. 누가 넣었는지(작성자)와 누구 일정인지(대상)가 함께 보여요.
- **체크리스트** 는 여러 번 지우고 다시 채우는 목록이에요. 항목을 체크해도 사라지지 않고, 완료 항목 정리 를 누를 때만 지워져요.
- **각자 할 일**(미션 탭)은 사람마다 따로 쓰는 오늘의 할 일이고, 체크리스트는 가족이 같은 목록을 같이 봐요.
- 세 기기 모두 같은 달력·체크리스트를 실시간으로 보고, 한 기기에서 넣은 일정·항목이 다른 기기에 바로 나타나요(Supabase 연결 시).

## 🐣 캐릭터 키우기 규칙

- **경험치** = ① 용돈으로 쌓은 경험치(누적 적립 100원마다 +1, 쓴 돈이 있어도 줄지 않아요) + ② 할 일·돌보기 경험치.
- ②는 **공부 항목 +4**(모두 끝내면 +8) · **다인 할 일 +3**(모두 끝내면 +8) · **가족 미션 +10** · **저녁 루틴 올클리어 +8** · **밥 주기 +2 · 놀아주기 +2 · 쓰다듬기 +1** · **올클리어 간식 +15**. 같은 항목은 하루에 한 번만(체크를 껐다 켜도 또 주지 않아요).
- **단계** (필요 경험치): Lv.1 알(0) → Lv.2 아기 요정(50) → Lv.3 꼬마 요정(140) → Lv.4 어린이 요정(280) → Lv.5 반짝 요정(460) → Lv.6 왕관 마스터(700).
- **돌보기**는 하루 횟수가 정해져 있고(밥 3 · 놀기 3 · 쓰다듬기 5), 다 쓰면 말풍선으로 알려 줘요. 자정이 지나면 횟수는 새로 시작되고 포만감 -35 · 기분 -20 만큼 배고파지고 심심해져요(친밀도는 그대로).
- **올클리어 간식**은 공부·(할 일이 있으면) 다인 할 일·저녁 루틴·가족 미션을 모두 끝낸 날 한 번 받아요.
- 레벨이 오르면 하단 🐣 탭에 배지가 뜨고, 키우기 탭에서 새 모습을 볼 수 있어요. 홈 맨 아래 인사 카드에 **Lv.배지 + 지금 모습**이 작게 보여요.

## 3대 기기 실시간 동기화 (Supabase)

지금은 `config.js` 에 Supabase 프로젝트가 연결돼 있어서 **세 기기(엄마 폰 · 아빠 폰 · 다인이 타블렛)가 같은 기록을 실시간으로 나눠 써요** — 달력 일정과 체크리스트도 여기에 포함돼요.
`config.js` 의 `supabase.url` / `anonKey` 를 비우면 이 기기의 브라우저 저장소(localStorage)만 쓰는 모드로 돌아가요(준비물 없이 바로 동작).
다른 Supabase 프로젝트로 옮기려면:

1. https://supabase.com 에서 프로젝트를 만들어요.
2. SQL Editor 에서 아래를 실행해 테이블을 만들어요:

```sql
create table if not exists family_state (
  id text primary key,
  payload jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now()
);
insert into family_state (id) values ('main') on conflict do nothing;

alter table family_state enable row level security;

create policy "family read"  on family_state for select using (true);
create policy "family write" on family_state for insert with check (true);
create policy "family update" on family_state for update using (true);
```

3. Project Settings → API 에서 **Project URL** 과 **anon public key** 를 복사해요.
4. `config.js` 를 열어 `supabase: { url: "...", anonKey: "..." }` 에 붙여 넣고 저장해요.
5. 앱을 다시 열면 끝! 설정 화면에 "실시간 동기화"라고 나오면 3대 기기가 같은 도장판·채팅·할 일·달력·체크리스트를 봐요.

> anon key 는 브라우저에서 공개되는 키예요. 가족 외에는 쓸 수 없도록 하려면 Supabase 대시보드에서 도메인 제한(RLS 강화·인증 추가)을 더할 수 있어요. 지정한 테이블 외에는 어떤 데이터도 읽지 않아요.

### 저장은 "덮어쓰기"가 아니라 "항목 단위 병합"

기기끼리 같은 기록을 나눠 쓰다 보면, 오래 켜 둔 기기(태블릿 등)가 옛 복사본을 통째로 올려서 다른 기기의 새 채팅·일정이 사라지는 일이 생길 수 있어요. 그래서 저장 방식을 이렇게 바꿨어요.

- **Read → Merge → Write**: 저장할 때 서버의 최신 상태를 먼저 받아오고, 이 기기가 바꾼 것만 얹어서 다시 올려요. 이 기기가 건드리지 않은 채팅·일정·체크리스트·루틴·말판은 서버 것을 그대로 써요.
- **항목(id) 단위 병합**: 채팅 메시지·달력 일정·체크리스트(리스트와 항목)·할 일·공부·성장 기록·말판 문구는 id 기준 합집합으로 합쳐요. 채팅은 시간순으로 정렬하고 개수(200)·사진(24장) 상한은 그대로 지켜요.
- **지운 것은 지운 채로**: 항목을 지우면 `state.deleted` 에 흔적(tombstone)을 남겨서, 다른 기기가 옛 복사본을 저장해도 되살아나지 않아요.
- **캐릭터는 뒤로 가지 않아요**: 경험치·용돈 경험치·본 레벨·친밀도는 큰 값(최신)을 써요.
- **다른 기기 변경을 받을 때도 병합**: 실시간·폴링으로 받은 상태를 통째로 갈아 끼우지 않고, 이 기기가 하던 일과 합쳐요.
- 같은 브라우저의 여러 탭(localStorage 모드)도 같은 규칙으로 합쳐요.
